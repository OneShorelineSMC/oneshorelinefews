# Creek fact sheets: draft for review

One page per creek in the flood early warning system (FEWS): where it runs, its gauges, its flood levels and alerts, and what those are based on. Each page opens with a short **What we need you to check** list; please answer by replying to the review request. Everything else on a page is background.

**Flood levels set?** Yes = creek heights tied to flooding, with a recorded meaning. "Yes, but what they mean isn't recorded" = heights are set but their meaning isn't written down. "None in FEWS (OneRain has some)" = FEWS has none, but OneRain's own system has levels whose basis isn't recorded. None = no creek height is tied to flooding yet; the creek's status comes from rain and how fast it is rising.
